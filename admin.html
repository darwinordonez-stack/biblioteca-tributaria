Sincronizar PDFs de Google Drive

Configuración de carpeta Drive

Ingresa el ID de la carpeta de Google Drive donde están los PDFs. El sistema comparará los archivos de Drive con los registrados en Supabase y mostrará los que faltan.

Nota: Esta herramienta no puede leer Drive directamente desde el navegador. Tienes dos opciones:

Opción 1: Pegar JSON de Drive

Ejecuta el Apps Script apps-script-sync-pdfs.js (función ejecutarManual) o pega aquí un JSON con formato {"nombre.pdf": "driveId", ...}

Opción 2: Automático con Apps Script

Configura el Google Apps Script para que sincronice automáticamente cada día:

  1. Ve a script.google.com
  2. Crea un proyecto nuevo
  3. Pega el código de apps-script-sync-pdfs.js
  4. Ejecuta configurarTriggerDiario()
  5. ¡Listo! Correrá cada día a las 7am
